## 📋 简介

**Lapis-IronFurnaces** 是经典模组 **[Iron Furnaces](https://modrinth.com/mod/iron-furnaces)**（源码 [Qelifern/IronFurnaces](https://github.com/Qelifern/IronFurnaces)）的**服务端复刻版**，
以 **Rebar 框架附属插件**的形式运行在 Paper 服务端上：熔炉等级、升级组件与核心机制尽量与模组保持一致，电力与物流则接入 Rebar 生态。

本插件为你的服务器添加**多级高级熔炉**，从铜到下界合金，9种不同速度的熔炉满足你所有需求！

### 🔁 与模组版的对照

**✅ 一样的**

- 9 个熔炉等级与速度：铜 180 / 铁 160 / 金 120 / 钻石 80 / 绿宝石 40 / 水晶 40 / 黑曜石 20 / 下界合金 5 tick
- 6 个升级组件与颜色槽位（红=高炉/烟熏、绿=速度/燃料、蓝=工厂/发电机），每个槽只能放 1 个
- 组件效果：速度=时间减半/燃料 ×2，燃料=热值 ×2/时间 +25%，高炉/烟熏=只烧对应配方，发电机=热量转电力且不再烧炼
- 工厂模式：禁用燃料槽、改用电力，6 入 6 出按等级开放 2/4/6，每个输入槽独立并行烧炼、各自一条进度条
- 工厂每件物品固定能耗（4000 J × 绿组件修正）：越快越耗电，但每件总能耗相同
- 发电机出力按等级（40~2000 W/t），绿组件修正与模组一致

**⚠️ 不一样的**

- 运行环境：Rebar 附属插件（Paper 服务端），不是 Forge 模组
- 电力：接入 Rebar 电网，没有模组那样的内部储能缓冲（Rebar 里储能是独立方块）
- 物流：用 Rebar 物流组替代模组的"每面自动输入/输出 + 自动均分"
- 红石：只做门控（忽略 / 有信号时停止 / 仅有信号时工作），模组的比较器输出未实现（Bukkit 无法让普通方块输出模拟红石信号）；被门控时是**暂停**而不是清空进度
- 高炉/烟熏额外有 ×2 燃料惩罚（模组只靠限制配方类型平衡）
- 彩虹熔炉：模组里它发电 2000 RF/t，本插件改成批量烧炼 + 颜色循环
- 模组的每面配置 GUI、经验收集、无线热能接收器未实现

### ✨ 核心特性

- 🔥 **9种熔炉等级** - 最快可达原版 **40倍** 速度
- ⬆️ **6种升级组件** - 自定义熔炉能力（加速、省燃料、自动化等）
- 🎨 **精美界面** - 基于 InvUI 的简洁操作界面
- 📊 **智能进度条** - 打火石进度条随烧炼**耐久度增加**
- ⛽ **燃料可视化** - 实时显示燃料类型和剩余时间
- 🌈 **特殊熔炉** - 彩虹熔炉（颜色变化+批量处理）、水晶熔炉（半透明）
- 🌐 **中文支持** - 完整的简体中文界面
- 🔌 **红石门控** - 熔炉界面右下角按钮切换：忽略 / 有信号时停止 / 仅有信号时工作
- ⚖️ **平衡机制** - 升级组件有负面效果，需要策略搭配

## 🚀 快速开始

### 安装步骤（30秒）

1. **安装 Rebar** - 确保 `plugins` 文件夹已有 Rebar 插件
2. **下载本插件** - 获取 `Lapis-IronFurnaces-1.2.1.jar`
3. **放入服务器** - 将 jar 文件放入 `plugins` 文件夹
4. **重启服务器** - 输入 `/reload` 或重启服务器

完成！🎉

### 获取熔炉

```minecraft
/rb give @p ironfurnaces:iron_furnace      # 铁熔炉
/rb give @p ironfurnaces:diamond_furnace   # 钻石熔炉
/rb give @p ironfurnaces:netherite_furnace # 下界合金熔炉
/rb give @p ironfurnaces:rainbow_furnace   # 彩虹熔炉
# ... 更多见下方"熔炉等级"
```

## 🎮 使用方法

1. **放置熔炉** - 像普通方块一样放置
2. **右键打开** - 点击熔炉打开操作界面
3. **放入燃料** - 底部槽位放燃料（煤炭、木炭等）
4. **放入物品** - 左侧槽位放要烧炼的东西
5. **取出成品** - 右侧槽位自动输出结果
6. **点击⚒️按钮** - 打开升级界面（可选）

就这么简单！

## ⬆️ 升级系统

熔炉支持 **6种升级组件**，每种都有独特效果和**负面平衡机制**：

### 升级列表

| 升级 | 效果 | 负面效果 | 槽位 |
|------|------|---------|------|
| ⚡ **速度升级** | 烧炼时间减半 | 燃料消耗 ×2 | 🟢 绿色槽 |
| ⛽ **燃料升级** | 燃料效率 ×2 | 烧炼时间 +25% | 🟢 绿色槽 |
| 🏭 **高炉升级** | 可烧制矿石/矿物 | 燃料消耗 ×2 | 🔴 红色槽 |
| 🚬 **烟熏炉升级** | 可烹饪食物 | 燃料消耗 ×2 | 🔴 红色槽 |
| 🏭 **工厂升级** | 最多 6 入 6 出、并行烧炼（按等级开放 2/4/6） | 禁用燃料槽，改用电力驱动 | 🔵 蓝色槽 |
| ⚙️ **发电机升级** | 将燃料热量转为能量 | 停止烧炼 | 🔵 蓝色槽 |

### 使用规则

- ✅ **同类型只能放1个** - 防止重复叠加
- ✅ **分类槽位放置** - 特殊烧制放红色，效率放绿色，自动化放蓝色
- ✅ **智能验证** - 放错位置会自动取消
- ⚖️ **平衡设计** - 强力升级有代价，需要策略搭配

### 推荐组合

| 场景 | 推荐配置 | 说明 |
|------|---------|------|
| 日常使用 | 速度+燃料 | 平衡速度与燃料消耗 |
| 批量矿石 | 高炉+速度 | 快速冶炼矿石 |
| 大量烹饪 | 烟熏炉+燃料 | 省燃料批量做食物 |
| 全自动 | 输出+输入+速度 | 完全自动化生产线 |

## 📝 更新日志

### v1.2.2 - 修复与配置

- 修复**破坏熔炉后挂在上面的电线不会被清理**的问题：Rebar 只在电线自身被移除时才断开节点，
  方块被破坏不会触发，现在熔炉被挖掉时会把落在这台熔炉上的电线掉出来并正常断开
  （已知限制：另一端在未加载区块里的线清理不到）
- 修复红石模式切换的消息和界面按钮里 `%mode%` 原样显示的问题：
  Rebar 的翻译器只替换 **RebarArgument** 类型的参数，直接传 `Component` 不会被替换
- **发电机模式对齐模组**：输入槽、输出槽、普通燃料槽全部隐藏（模组里这三个槽的 `isActive()`
  都是 `isFurnace()`），改为在界面中间放一个专用的发电机燃料槽；
  如果拆掉工厂升级时槽里还有残留物品，会把输入/输出槽一并显示出来方便取回
- 新增 **`config.yml`**（自带中英双语注释，首次启动生成在插件目录）：
  - `multiplier.power` / `multiplier.fuel` / `multiplier.speed` —— 三个整体倍率，**相乘关系**、各自只作用在自己那一类数值上
  - `generation.<等级>` —— 各等级熔炉作为发电机时的出力（瓦特/刻）
  - `consumption.energy-per-item` —— 工厂模式每件物品的耗电（焦耳）
  - 读不到的项一律回退到代码里的默认值（即模组原值），所以缺项不会出问题

### v1.2.1 - 修复与对齐

#### 社区反馈

- 升级组件「工业升级」更名为「**工厂升级**」（内部键 `industrial_upgrade` 保持不变，已有物品不受影响）
- 工厂升级现在禁用燃料槽，并把输入/输出槽位纵向排列为「上排 3 入、下排 3 出」
- 熔炉电力端子由放下即生成 6 个改为**顶部 1 个输入/出端子**（与电炉一致）
- 修正熔炉前面板展示实体：轴向位移过大导致面板凸出方块表面，并补上径向的微小缩小
- 修复金属块熔炉被原版当作傀儡材料的问题：铜傀儡会把铜熔炉换成铜箱、铁傀儡会清掉铁熔炉，现在会拒绝该次南瓜放置

#### 与模组版（Iron Furnaces）源码对齐

- 工厂模式完全对齐模组：**6 个输入槽 + 6 个输出槽**，按炉子等级开放 2/4/6（铜/铁 2、金 4、钻石及以上 6），
  GUI 改成「上排输入 / 中排进度 / 下排输出」，**每个输入槽独立并行烧炼、各自一条进度条**
- 工厂的烧炼进度会随方块一起持久化（对齐模组的 `FactoryCookTime` / `FactoryTotalCookTime`）
- 新增红石门控：熔炉界面**右下角按钮**切换「忽略 / 有信号时停止 / 仅有信号时工作」，WAILA 显示当前模式
  （模组里这是配置 GUI 里的设置项；模组的「比较器模式」只剩翻译字符串、并未实现，且 Bukkit 无法让普通方块输出模拟红石信号，故未做）
- 速度升级的燃料代价由 +50% 改为 **×2**（模组 tooltip：*Uses up twice the amount of fuel*）
- 工厂 + 高炉/烟熏组合现在也享受高炉的 0.5 时间修正（此前只有非工厂模式生效）
- 发电机出力改为**按熔炉等级**：铜/铁 40、金 160、钻石 240、绿宝石 320、水晶 360、黑曜石 500、下界合金 1000、彩虹 2000 W/t
- 发电机绿组件与模组一致：速度 → 出力 ×2 / 燃烧 ×2（每单位燃料总发电量不变）；燃料 → 出力 ×0.75 / 燃烧 ×0.5（总发电量 ×1.5）
- 发电机燃烧燃料不再按炉子速度缩短燃烧时间，因此高级炉子每单位燃料能发出更多电
- 工厂电力改为「每件物品固定能耗」（4000 J × 绿组件修正），与炉子等级无关：越快越耗电，但每件物品总能耗相同
- 燃料耗尽时烧炼进度改为按模组的方式**缓慢回退**（每 tick 退 2 tick），而不是立刻清零
